MailGuard Score

Know if that email is safe before you click.

A Gmail sidebar that scores the open message for phishing and malware — no mailbox stored on our servers.

Install steps

Your API key

Copy this into the Gmail add-on User property named API_KEY.

Keep this private. Anyone with it can score mail through your account quota.

Install

  1. Sign in above and copy your API key.
  2. Install the Gmail add-on (test deploy link or Marketplace listing when published).
  3. In the Apps Script project, set Script property BACKEND_URL (and REQUEST_SIGNING_SECRET if your host requires it).
  4. Set your personal API_KEY as a User property.
  5. Open any Gmail message — the sidebar scores it on demand.

Privacy

Scoring is request/response only. We do not keep your mail. Optional AI review uses a redacted body. Report phishing and Block sender only change labels and filters in your Gmail.
