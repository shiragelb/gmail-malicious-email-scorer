Hard tests — not a virtual machine

The main Gmail scorer is not a virtual machine. It never boots a machine, never opens the links, and never runs the message. It reads authentication headers, wording, and known-bad URLs. An on-demand deep scan asks VirusTotal for reputation. That is still a lookup, not a VM. The sandbox demo is further down this page — not in the sidebar.
